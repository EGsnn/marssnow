# Community Chinese font

Noto Sans SC variable font from Google Fonts, licensed under SIL OFL 1.1.
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
SHA-256: a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da

The community FCN1 bitmap is regenerated from this source by
`scripts/generate_community_assets.py`. It replaces the original development
font generated from a macOS system font. The font and derived bitmap remain
under OFL; see OFL-NotoSansSC.txt. Pillow is required only for regeneration.
