# 安装与分区

本次提供源码构建，不提供针对任意现存设备的一键刷写程序。

1. 确认设备型号与 `firmware/boards/<板型>.json` 的芯片、Flash、PSRAM、屏幕及引脚一致。
2. 读取现有分区表、运行槽和设备配置，备份完整 Flash，确认有可用的恢复方法。
3. 与 `firmware/mars_system/partitions.v2.csv` 逐项比较。旧布局、第三方固件和 C3 设备不能直接套用。
4. 已匹配的 V2 设备更新时，只向经核实的系统槽写入系统载荷；保留 NVS、uidata、独立应用和其他分区。资源包按设备实际 assets 分区单独处理。
5. 新设备初始化涉及 bootloader、分区表、引导数据、系统和 assets，必须为该设备制定完整方案。构建产物并不自动构成可直接执行的安装清单。
6. 烧录后独立读回校验、确认启动，再在设备上验证屏幕、实体输入、触摸、进入退出和持续运行。

`build-manifest.json` 是构建产物清单，`hardwareVerified: false` 表示本次编译没有完成实机验收；不能据此推断设备当前地址和运行状态。

动态应用安装需遵循 MARSAPP 校验以及包先写入、安装记录后提交的存储协议。不要随意覆盖三个物理应用区域，或将旧的固定槽安装流程用于新记录布局。
