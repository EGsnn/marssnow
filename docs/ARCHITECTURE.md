# 架构与开源边界

启动链：`app_main → mars_board_init → 系统服务 / 动态应用扫描 → launcher_run`。
系统持有底层硬件；应用通过公开 ABI 调用绘图、输入、时间、音频和网络能力。

- `mars_bsp`：板型、LCD、触摸、实体输入与音频适配。
- `mars_common` / `mars_canvas` / `mars_ui` / `mars_ui_adapt`：画布、字体、页面、转场及显示交接。
- `mars_core`：分区、启动、应用登记与存储扫描。
- `mars_app_loader`：MARSAPP 校验、ELF 重定位、导出符号和运行生命周期。
- `mars_services` / `mars_audio_stream`：供动态应用调用的公共服务与缓冲队列。
- `mars_net` / `mars_clock` / `mars_ota`：联网、时间与升级基础设施。

桌面与应用共用显示资源，必须保持唯一显示所有者。动态应用首帧经过握手后再进入转场；关闭应用时先同步停止其任务和后台服务，再释放内存、资源映射与显示权。不要把后台回调指向已卸载的应用代码。

## 公开内容

系统框架、设备驱动、编译配置、公开 ABI、应用打包工具、基础内置系统功能与最小示例。
`main/apps` 是启动器和系统交互代码，不是闭源独立应用的源码目录。

## 未包含内容

配套手机 App、网站前后端、云端运营和应用市场服务、独立产品应用源码与安装包、产品表情包、语音识别模型、设备数据和原开发仓库历史。ESP32-C3 compact 分支待应用与系统拆分后再评估公开。

系统内的 BLE 配置和时间服务属于设备固件；保留这些代码不代表公开平台网站。
IP 时区自动识别仍会访问第三方公共时间服务；基础桌面可以离线启动，联网和校时需要用户自行配置网络。
