# MARSSNOW development

Read README.md and docs/ARCHITECTURE.md before editing. Keep device applications,
website, mobile clients, credentials and device data outside this repository.
Preserve the existing Apache-2.0 license and third-party license boundaries.
Build artifacts belong in ignored build directories. Never flash a device merely
to verify compilation. Display, touch and audio claims require real-device evidence.
Keep the single display-owner and synchronous app teardown contracts.
